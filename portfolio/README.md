# Isra Samoo | Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript. No build step.

**Live site:** https://israsamoo.github.io/portfolio/

## Run locally
Open `index.html` in a browser, or use the VS Code **Live Server** extension.

## Structure
```
index.html        page content
css/style.css     design tokens and styles
js/script.js      mobile menu, active nav link, footer year
assets/           images, icons, public-safe CV
```

## Before publishing
- Add `assets/documents/Isra-Samoo-CV.pdf` (a web version without phone number).
- Replace the dashed screenshot boxes in `index.html` with sanitized images.
- Never commit employer files, credentials, or real personal data.
